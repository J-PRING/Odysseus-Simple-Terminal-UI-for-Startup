I made this for use on Linux Mint Cinnamon.

Download the file and place it where you like.

in a terminal:
- cd to file location
- give file permissions
    sudo chmod +x odysseus_mgr.sh
- run the script
    ./odysseus_mgr.sh

To make this file easier to access, you can run it using a simple terminal command by adding an alias to your '.bashrc' file found in your user directory '~'.
- open .bashrc in a text editor
- add this line:

    alias odysseus='~/odysseus_mgr.sh'

- save.

You should now be able to type 'odysseus' into your terminal to run odysseus_mgr.sh.

Be sure to replace '~/odysseus_mgr.sh' with the correct file path if it's not in the home directory.
You can also change 'odysseuss' to anything you want.

Hope this helps you out.
